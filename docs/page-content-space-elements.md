# Вертикальные отступы на страницах Moontrail

## Резюме

Кастомные страницы MoonShine рендерят соседние блоки без `.space-elements` ([moonshine#2108](https://github.com/moonshine-software/moonshine/issues/2108)). На индексной странице лога зазоры между KPI, фильтрами и чипами задавались через `mb-4`/`mb-3` и `margin-bottom` в CSS. Теперь эти блоки один раз оборачиваются трейтом `WrapsPageComponentsInSpaceElements`. Внутренние отступы карточек и полей формы не менялись. Заголовок страницы по-прежнему рисует лейаут, снаружи обёртки.

Пакет один на MoonShine 4.8 и 5.0 (`main`). Ветку `feature/moonshine-5` не обновляли: она остаток уже влитого PR #1.

Трейт можно удалить, если в ядре MoonShine появится opt-in на корне контента.

## План

1. Добавить трейт с `wrapInSpaceElements()`.
2. Обернуть визуальные блоки `MoonTrailIndexPage::topLayer()`; `<link>` стилей оставить снаружи; кнопки индекса и их `LineBreak` — тоже снаружи (на обёртке `mb-6`, чтобы сохранить зазор).
3. Убрать межблочные `mb-4`/`mb-3` из blade и дублирующий `margin-bottom` у `.ms-al-kpi-grid` и `.ms-al-inline-filters`.
4. Тест на обёртку `topLayer()`.
5. PR в пакет, без мержа и релиза.
